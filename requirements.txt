#   - sse-starlette + starlette are pinned because mcp's newer releases (irrespective
#     of the pydantic issue above) pull in sse-starlette>=3.x, which requires
#     starlette>=1.0 — that breaks fastapi==0.115.0 (needs starlette<0.39). This exact
